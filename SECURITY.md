# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: open the **Security** tab of the
repository and choose **Report a vulnerability**. If that option is not
available for the repository, open an issue that only says you have a security
report, without details, and wait for a private channel.

Include what you found, how to reproduce it and the impact you expect.

## What to expect

These are personal projects maintained by one person, so there is no response
time guarantee. Valid reports are fixed as soon as possible and credited in
the release notes if you want.
